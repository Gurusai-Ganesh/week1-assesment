# Week 1 Assessment

## Project Overview

This project contains four tasks completed as part of the Week 1 Python and Data Engineering assessment.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Requests
- Git
- GitHub
- Jupyter Notebook

## Project Structure

- data: Employee and department datasets
- src: Python source code
- notebooks: Jupyter notebooks
- reports: Generated charts

## Setup Instructions

### 1. Clone the repository

git clone https://github.com/Gurusai-Ganesh/week1-assesment

### 2. Create virtual environment

python -m venv venv

### 3. Activate environment

Windows:

venv\Scripts\activate

### 4. Install dependencies

pip install -r requirements.txt

### 5. Run Task 1

python src/task1.py

### 6. Run Task 2

python src/task2.py

### 7. Run Task 3

python src/task3.py

## Findings

1. The IT department has the highest average salary.
2. Five employees earn above 50000.
3. Chennai has four employees.
4. Karthik has the highest salary in the dataset.
